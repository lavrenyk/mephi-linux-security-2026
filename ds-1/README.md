# ДЗ №1 — Безопасность Linux

В папке `ds-1` находятся материалы ДЗ №1. Таблица ниже описывает выполнение пунктов этого домашнего задания. Пути `etc/*` обозначают сохранённые копии файлов `/etc/*` из учебной системы.

| Файл | Раздел | Как выполнен пункт и что проверяется |
| --- | --- | --- |
| `mephi-screenshot.png` | 6 | Скриншот для визуального подтверждения выполнения задания. |
| `history.out` | Все | История выполненных команд: поиск SUID-файлов, мониторинг процессов, настройка SUID и capabilities, работа с sudo и системным временем. |
| `stat.out` | 1, 3, 4 | Домашний каталог `/home/user1` имеет права `0700` и владельца `user1:students`; `my_cat` принадлежит `root:root` и имеет права `4755` (SUID); `my_chown` имеет права `0755`. |
| `getcap.out` | 4 | Утилите `/home/user1/my_chown` назначена capability `cap_chown=ep` для изменения владельца файлов. |
| `etc/passwd` | 1 | Учётная запись `user1`: UID `1234`, основная группа с GID `1001`, домашний каталог `/home/user1`, оболочка `/bin/bash`. |
| `etc/shadow` | 1 | Сохранённые параметры паролей и сроков их действия для проверки настройки учётных записей. |
| `etc/group` | 1 | Группа `students` имеет GID `1001`, соответствующий основной группе пользователя `user1`. |
| `etc/sudoers` | 5 | Сохранена конфигурация sudo, включая подключение файлов из `/etc/sudoers.d`. В `history.out` записаны редактирование правила `user1_time` через `visudo`, установка прав `0440` и вызовы `sudo timedatectl`. |
| `suid_files.out` | 2 | Результат поиска файлов с SUID-битом командой `find / -perm -4000 -type f 2>/dev/null`; в списке присутствует `/home/user1/my_cat`. |
| `processes.out` | 2 | Результат отбора процессов с EUID `0` и RUID не менее `1000`; найден `fusermount3` с PID `1936`, RUID `1234` и EUID `0`. |

Файл `/etc/sudoers.d/user1_time` отсутствует среди сохранённых материалов, поэтому точный состав разрешённых пользователю команд по имеющейся копии `etc/sudoers` проверить нельзя.
